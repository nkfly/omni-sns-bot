| 1 | [`01-account-profile.md`](01-account-profile.md) | `profile.yaml` |
| 2 | [`02-voice-and-style.md`](02-voice-and-style.md) | `style-guide.yaml`, optional `style-notes.md` |

| 4 | [`04-faq-and-replies.md`](04-faq-and-replies.md) | `faq.yaml` |

Read them in that order the first time. After setup, the operating loop tells you which one to reopen.
