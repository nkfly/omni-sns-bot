# Instagram

**Status: not implemented.** Do not post or reply.

Instagram is a different Meta product from Threads. A Threads user token and `graph.threads.com` do not publish Instagram posts. A future adapter needs its own official docs, app review story, and the checklist in [`docs/adding-a-platform.md`](../../docs/adding-a-platform.md).

If the editor wants Instagram, record `instagram` on `profile.account.also_platforms` and keep using the Threads adapter for Threads only.
