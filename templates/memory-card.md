# Memory card

Use this only when you cannot keep a workspace on disk. Follow the [memory-card loop](../docs/operating-loop.md#memory-card-loop): `draft_only`, `always_ask`, and manual publication in the current conversation. No OAuth, API/browser publishing, or scheduled actions. It is not a place for tokens, cookies, or passwords. If you can write files, use the workspace instead and ignore this card.

At the end of a session, show the updated card to the editor. At the start of the next one, ask for it if you cannot recall it.
