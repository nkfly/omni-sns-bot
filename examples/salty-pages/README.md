# 鹽與頁 Salty Pages — fictional example

This account is **made up**. There is no shop at this address, the handle is not a real client, and the posts were never published. It exists so a bot can see what a finished workspace looks like after setup. Do not copy the facts into a real account, and do not post the captions.

| | |
| --- | --- |
| Brand | 鹽與頁 (Salty Pages) |
| Handle | `@saltypages` |
| What it is | A one-room bookstore in Tainan that also sells sea-salt caramels |
| Language | Traditional Chinese. English only for a book title. Japanese rarely, for the owner's own paperbacks. |
| Mode in the example | `api`, approval `always_ask` |
| Voice path | `both`: a small corpus in `sources/past-posts.md`, then the guide |

Read in this order:

1. `profile.yaml` — purpose, cadence, do/don't, approval
2. `style-guide.yaml` — measurable voice, gold posts, reply rules
3. `faq.yaml` — the only facts a reply may use, plus three triaged comments
4. `calendar.yaml` — one published post, one approved, one waiting, one rejected AI-sounding draft, one `needs_facts`
5. `sample-posts.md` and `sample-replies.md` — why those texts passed or failed

The private-workspace rules still apply to real editors. This folder is the exception that is allowed in git because every fact in it is fiction.
