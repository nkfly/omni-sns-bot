# 貼文為什麼過、為什麼被退

帳號是虛構的。下面只示範自檢，不是叫你拿去發。

## 過了：`2026-11-06-pencil`

> 今天進門先聞到紙。新到的一批二手詩集還有上一個人的鉛筆線，我留著，沒有擦。

| 項目 | 結果 |
| --- | --- |
| voice | 過。兩句、沒有招呼、長度接近金牌貼文。 |
| specific | 過。紙味、鉛筆線，換一家店就寫不出這句。 |
| banned | 過。沒有總論，沒有「一起」。 |
| emoji / hashtag | 過。零。 |
| facts | 過。鉛筆線是編輯當天講的，所以還放在 `pending_approval`，沒有直接發表。 |
| language | 過。繁體中文。 |

自檢過了仍然要等編輯，因為政策是 `always_ask`。

## 退了：`2026-11-03-rejected-slogan`

> 在這個快節奏的時代，閱讀是一種對心靈的投資。今天為大家精選三本不容錯過的好書，讓我們一起開啟閱讀之旅吧！

硬性失敗：`banned`（在這個快節奏的時代、為大家精選、不容錯過、讓我們一起、閱讀之旅）、`specific`（換成任何書店都成立）、`shape`（總論加號召）、`voice`（驚嘆號，金牌貼文是零）。

不要把這篇修成「在這個快節奏的時代，我們店的燈還在閃」。第一句就該刪掉，從燈或書開始。日曆裡它是 `rejected`，不是 `draft`。同一個骨架不要換同義詞再送。

## 還不能寫：`2026-11-11-reading-night`

想辦一場週五夜讀。日期、要不要報名、人數都不在 FAQ。狀態停在 `needs_facts`。不可以先寫「本週五晚間七點，限量十五位」來顯得具體。那是編出來的事實。
